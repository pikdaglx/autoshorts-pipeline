# Política de Privacidade — AutoShorts Pipeline

Este aplicativo é uma ferramenta de automação local e pessoal para edição e publicação de vídeos curtos no YouTube Shorts via YouTube Data API v3 e Google APIs.

## Coleta e Uso de Dados
- O aplicativo acessa apenas as permissões OAuth 2.0 explicitamente autorizadas pelo próprio usuário proprietário do canal.
- Nenhum dado pessoal, credencial ou token é compartilhado, vendido ou transferido a terceiros.
- Os arquivos `client_secret.json` e `token.json` permanecem armazenados exclusivamente na máquina local ou nos GitHub Secrets privados do próprio usuário.
